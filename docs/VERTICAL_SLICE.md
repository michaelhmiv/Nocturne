# First vertical slice

The first playable path should prove the universal content and AI-GM architecture end to end.

1. A player creates an account and character.
2. The character rents an apartment in Foundry Row.
3. The player describes a custom surveillance system in natural language.
4. The creative model may brainstorm the concept.
5. The authoritative model normalizes the concept into traits, effects, requirements, costs, signatures, limitations, and counters.
6. The backend validates whether the apartment supports installation.
7. The system persists a provisional definition and a specific installed instance.
8. The player enters: "Scan the alley behind my building for suspicious movement."
9. The API parses intent, assembles viewpoint-limited context, and validates feasibility.
10. The rules engine resolves detection with a recorded seed and calculation trace.
11. The event ledger commits the result.
12. The creative model narrates only the committed event.
13. The web client displays the narration, information gained, costs, and changed state.

This slice should be completed before broad combat, economy, or map expansion.
