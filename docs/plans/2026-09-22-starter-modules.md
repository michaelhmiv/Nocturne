# Starter modules

Ship this loop. Do not add cars or extra guns until it is live.

1. Category travel through `submit()` using OSM bind + `buildCityTravelPlan`.
2. One cell: apartment origin + fixture (or later extract) families.
3. Look / take / buy / eat / talk / wait on that cell after travel works.
4. Later modules reuse primitives: occupy/drive, operate/damage, heat, second body.

A new shop is a lexicon phrase + OSM tag row + one surface test.
