# Nocturne revival: accepted product contract and implementation register

The standalone website is the primary client: conversational play with status, progression, map, and live city news. Real NYC geography contains fictional people and businesses. Ordinary humans can attempt arbitrary plausible actions; superpowers are excluded. ChatGPT/MCP remains an optional client of the same authoritative API.

The core loop is explore/interact, earn/spend, and cause/respond to trouble. Skills, assets, and reputation provide progression. Elections, cosmetics, and autonomous NPC ambitions are deferred. NPCs are stationary but reactive, including witnesses, merchants, and incident-triggered police.

Characters and property remain vulnerable offline. Defeat uses accelerated GTA-style recovery, while theft, damage, legal consequences, and reputation persist. The social preference approach/keep-to-self controls voluntary social contact, never immunity. Encounters depend on location, routes, visibility, and access. Missing response windows use a standing self-preservation policy (escape when feasible, surrender when cornered), not an automatic fight to the death.

Only reported/public evidence reaches the newspaper. An unidentified robbery can be reported without identifying its offender; undiscovered crimes remain unpublished. Narration, status, map, history, and other players must agree with committed state.

## AI authority

OpenRouter is the user-authorized model gateway. The live evaluation discovers model availability rather than assuming every provider/model is present. Jev is intended for bounded choices, reference matching, plausibility and reactions; generative models retain complex proposals and narration. Jev availability and typed-interface support must be verified before activation. Never present another model as Jev.

Backend validation owns inventory, ownership, money, physical state, clocks, rolls, and atomic commits. Decision confidence is not game success probability. No AI decision, however confident, bypasses invariants. The initial diagnostic model comparison is not sufficient for release certification.

## Test policy

GitHub Actions is mandatory. Deterministic tests require no paid key. Live evaluation requires OPENROUTER_API_KEY and reports missing access as blocked/failed, not passed. Secret-bearing tests execute trusted code only. Every behavior needs player-visible and authoritative assertions, and failures retain sanitized logs/traces/screenshots. The old manual-only and MCP-primary documents are superseded by this contract.
